# MACH OVERDRIVE 高速機甲：超限驅動

Run: `npm install && npm run dev` (Vite). Build: `npm run build` → single-file `dist/index.html` (open directly in Chrome/Edge/Safari).

Debug URL params: `?ch=0..4` start chapter (0 city, 1 highway+elite, 2 fleet+battleship, 3 tunnel, 4 boss), `&auto` skip title, `&god` invincible, `&fps` show perf, `&bot` autopilot, `&test` fixed-step low-res headless mode.

Controls: WASD fly · mouse aim · LMB fire · hold RMB/E multi-lock, release to fire missiles · F blade · Shift boost · Space dodge · P pause · M mute.
